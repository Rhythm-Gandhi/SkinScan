# SkinScan Assistant ✨💖

**SkinScan Assistant** is your ultimate "Glow-Up Procurement Partner." It's a specialized skincare product assistant that uses AI to identify products from images, rank them based on key criteria, and find the best buying links instantly.

## ✨ Features

- **Visual Product Identification**: Snap a photo or upload an image to identify brand, product name, and variant.
- **📊 Detailed Product Ranking**: Get a score out of 10 for:
  - **Ingredients**: Quality and safety analysis.
  - **Usage**: Ease of integration into your routine.
  - **Effectiveness**: Reputation and clinical/user results.
- **🛒 Functional Buying Links**: Direct links to major retailers (Amazon, Sephora, Nykaa, etc.) or Google Shopping search links.
- **📸 Dual Capture Modes**: Use your device's camera for live scanning or upload from your gallery.
- **🌸 Aesthetic UI**: A beautiful, feminine design with rose-pink gradients, elegant typography, and playful animations.
- **🛡️ Safety First**: Integrated reminders to check ingredients for potential allergies.

## 🚀 Technologies Used

- **React 19**: Modern functional components and hooks.
- **Visual Recognition Engine**: Advanced visual analysis and entity extraction.
- **Tailwind CSS**: Utility-first styling with a custom rose/pink palette.
- **Motion (Framer Motion)**: Smooth, interactive animations.
- **Lucide React**: Beautiful, consistent iconography.
- **React Markdown**: Clean rendering of AI-generated reports.

## 🛠️ Setup Instructions

### Prerequisites

- Node.js installed on your machine.
- A valid service credential.

### Installation

1. **Clone the repository** (or download the source).
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Configure Environment Variables**:
   Create a `.env` file in the root directory and add your service credential:
   ```env
   SERVICE_CREDENTIAL=your_credential_here
   ```
4. **Start the development server**:
   ```bash
   npm run dev
   ```
5. **Open the app**: Navigate to `http://localhost:3000` in your browser.

## 📝 Usage

1. **Capture**: Click "Take Photo" to use your camera or "Upload Photo" to select an image from your device.
2. **Identify**: Click the "Identify Product" button to start the AI analysis.
3. **Review**: Check the "Beauty Report" for product details and rankings.
4. **Shop**: Click on the retailer links to purchase the product directly.
